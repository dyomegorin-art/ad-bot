# AdBot — рассылка нового ролика YouTube в комментарии Telegram-каналов

Программа следит за вашим YouTube-каналом. Как только выходит новый ролик, она
пишет ссылку комментарием под последним постом каждого канала из списка
(для каждого канала можно задать свой текст).

## Инструкция для пользователя (AdBot.exe)
1. Получите ключи Telegram: откройте https://my.telegram.org → войдите по номеру →
   **API development tools** → создайте приложение (название любое). Скопируйте
   **api_id** и **api_hash**.
2. Запустите `AdBot.exe` и вставьте api_id, api_hash и ссылку на свой YouTube-канал
   (подойдёт `https://www.youtube.com/@имя`).
3. Впишите каналы в блок «Каналы» (по одному на строку, формат в подсказке).
4. Нажмите **Запустить**. В первый раз программа спросит номер телефона и код из
   Telegram — это вход в ваш аккаунт, делается один раз.
5. Кнопка «Тест» сразу отправляет последний ролик во все каналы — удобно проверить.
   Окно можно свернуть, но не закрывать: пока программа открыта, она работает.

Настройки и вход сохраняются в `%APPDATA%\AdBot` (на Linux — `~/.config/AdBot`).

## Сборка
- **Windows (.exe) без Windows-машины:** залейте проект на GitHub — вкладка Actions →
  Build → скачайте артефакт `AdBot-windows`.
- **На Windows:** запустите `build.bat` → `dist\AdBot.exe`.
- **Linux:** `./build.sh` → `dist/AdBot`.
- Запуск без сборки: `pip install -r requirements.txt && python app.py`.
